## 1. Engine & Save Architecture Notes

- **Project Owl (`gmd::GameDataMgr`)**: Switch 2 OoT uses the *Tears of the Kingdom* engine (`sead` / `agl` / `gsys` / `Phive`). Live game flags and save files use **32-bit `murmur3` (seed `0`)** hashes over UTF-8 flag names, organized by typed sections (`section = manager + kind * 0x60`: `count` at `+0x10`, `entries, hash_table` at `+0x18`, `slots = count * 2` at `+0x2C`).
  - `kind = 0`: Bool table (`stride = 24`, bool byte at `entry + 22`).
  - `kind = 2`: Int32 table (`count = 1,259` in `v131072`, `stride = 40`, `s32`/`u32` value at `entry + 0x1C`).
  - `kind = 4`: Float32 table (`count = 89` in `v131072`).
  - `kind = 16`: String64 table (`stride = 0x108`, `char*` pointer at `entry + 0x68`).
- **Save files (`slot_00`..`slot_05`)**: `progress.sav` + `caption.sav` + root `option.sav`. `progress.sav` starts with `<III` `(magic = 0x01020304, version = 0x002D80EB, kv_end_offset)`, followed by 8-byte `<II` `(hash, value)` pairs from `0x28..kv_end_offset`, and a sorted `<Q` 64-bit collected-object ID array starting at the offset stored under key `0xA3DB7114` (terminated by `0`).
- **Font on RomFS (`companion-convergence.md` rule)**: decode Rodin NTLG Bold on-device from the owner's RomFS (`Font/*.bfarc.zs` compressed with `Pack/ZsDic.pack.zs`); never bundle Nintendo font or icon assets in the repository or APK.
